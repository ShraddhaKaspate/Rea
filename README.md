# LinkUP – Real Time Chat Application

LinkUP is a **real-time chat application** that allows users to communicate instantly through one-to-one messaging.
The application enables seamless messaging using **Socket.IO** for real-time communication and provides a responsive and interactive user interface.

This project demonstrates **full-stack web development using the MERN stack (MongoDB, Express.js, React.js, Node.js)** along with real-time communication technologies.

---

## Features

* Real-time one-to-one messaging
* Instant message delivery using Socket.IO
* Secure user authentication system
* Responsive and user-friendly chat interface
* Efficient backend APIs for communication
* Message storage using MongoDB
* Full-stack architecture with separate frontend and backend

## Installation & Setup

### 1. Clone the repository

git clone https://github.com/ShraddhaKaspate/LinkUP---RealTime-chat-application.git

### 2. Navigate to the project folder

cd LinkUP---RealTime-chat-application

### 3. Install backend dependencies

cd server
npm install

### 4. Install frontend dependencies

cd client
npm install

### 5. Run backend server

npm start

### 6. Run frontend application

npm start
